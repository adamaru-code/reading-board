# 画面プロトタイプ（HTML / CSS / JS のみ）

本番実装（Rails API + Vue 3）に着手する前の **画面イメージ認識合わせ用** の触れるモックです。
バックエンド・ビルドツール不要で、ブラウザで開くだけで動きます。

## 開き方

基本のボード操作・手入力だけなら、ファイルを開くだけで動きます：

```bash
open prototype/index.html
```

**バーコード読取・ISBN自動補完まで試す場合は localhost で起動してください**
（カメラは secure context 必須、API fetch も file:// では制限されるため）：

```bash
cd prototype && python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く（Chrome / Edge 推奨）
```

※ ポート 8000 はこのプロトタイプ専用（本番の Rails 3000 / Vite 5173 / MySQL 3306 とは無関係）。

## できること

[docs/screen-design.md](../docs/screen-design.md) の S1〜S4 に対応：

- **S1 カンバンボード**：3カラム（読みたい / 読書中 / 読了）＋各見出しに件数
- **S2 書籍カード**：タイトル・著者・★評価・**日付**。**ドラッグ&ドロップ**で別カラムへ移動（＝ステータス変更）
  - 日付は「そのカラムに入った日」を表示：読みたい=**登録**日 / 読書中=**開始**日 / 読了=**読了**日（日付のみ）。カラム移動や編集での状態変更時に自動で記録されます
  - 記録は**履歴として追加**されます（上書きではなく）。同じカラムに複数回入ると日付が複数表示されます（例 再読で「読了 2026/06/10、2026/07/01」）。同一日の重複は追加されません
  - 読了カードには**開始→読了の所要日数**（例「開始→読了 21日」）を表示します。開始日（最初の読書中日）が無い場合は非表示
- **読了カラムの並び替え**：読了列ヘッダの選択（読了日 / 評価 / 登録日 / 所要日数）と ↑↓ ボタンで並び替え（既定：読了日・降順）。算出できないカードは末尾に並びます
- **S3 追加**：「＋ 追加」ボタン → モーダル。タイトル必須バリデーションあり
  - **ISBN/バーコードから登録**：ISBN（13桁 / 10桁）を入力→「検索」で [openBD](https://openbd.jp/) からタイトル・著者・書影を自動補完。「📷 読取」でカメラからバーコード（ISBN）を読み取り自動補完（対応ブラウザ＋localhost のとき表示）
  - 雑誌（491 始まりのJAN）は openBD 非対応のため自動取得できず、タイトル手入力に誘導されます
  - 見つからない・オフライン時も手入力で登録できます
- **S4 編集**：カードクリック → モーダル。★評価・感想メモ・ステータス変更・削除
- **レスポンシブ**：画面幅 640px 以下で3カラムが縦積みになる

## 注意（モックの制約）

- **状態はメモリ上のみ。リロードすると初期サンプルデータに戻ります**（永続化・API通信なし）
- あくまで画面イメージ確認用。本番の実装コード（`frontend/`）とは別物です
- データモデル・status enum は [docs/database-design.md](../docs/database-design.md) に準拠しています
- ISBN/バーコード登録を本採用する場合、実 Book モデルに `isbn`（またはコード）カラムの追加が必要になります（本プロトタイプでは表示用に保持するのみ）
- バーコード読取は `BarcodeDetector` API 利用のため Chrome / Edge が対象（Safari / Firefox 非対応）
