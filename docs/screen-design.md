# 読書管理アプリ — 画面設計

> この文書は [要件定義書（概要）](requirements.md) から分割した詳細ドキュメントです。
> 画面・部品（S1〜S8）とその表示項目・操作・レスポンシブ挙動をまとめます。
> 画面遷移図・データフローの図解は [基本設計（図）](basic-design.md) を参照してください。

関連：[機能要件](functional-requirements.md) / [データベース設計](database-design.md) / [技術スタック](tech-stack.md)

対象デバイス: PC 優先。スマホ/タブレットではレスポンシブに再配置する（非機能要件は [要件定義書](requirements.md) 参照）。

画面の見た目・操作感は [`prototype/`](../prototype/)（HTML/CSS/JS のモック）を出発点とし、本書は現在の実装（`frontend/src/components/`）に合わせて記述する。

## 1. 画面一覧

|---|---|---|

| S8 | 読了一覧 | 読了本だけを 1 冊 1 行で左右 2 段に並べ、一度に多く見る |

## 2. S1 カンバンボード

- **表示項目**：3 カラム（読みたい / 読書中 / 読了）。各カラム見出しにカラム名＋件数（総件数）。カラムの上の線（とドラッグ中の点線）の色は、読みたい＝紫 `#6554c0`・読書中＝ピンク `#e2317a`（「今読んでいる」勢いを出す。エラーの赤とは色味を離す）・読了＝緑 `#22a06b`（`src/style.css` の `--col-*`）。件数のバッジも同じ色味の地に白い太字（白文字が読みにくいピンク・緑は同じ色味で少し濃い `--col-*-strong` を使い、コントラスト 4.5:1 以上）。各カラム内に書籍カードを縦に並べる。
- **ページング**：各カラムは初期 20 件。続きがあればカラム末尾に「もっと見る（残り N 件）」ボタンを出し、押すと 20 件ずつ追加する。
- **ヘッダ**：3 つのグループに分け、狭い画面ではグループごとに折り返す。
  - 左：タイトル＋「**＋ 本を追加**」（「読みたい」カラムと同じ紫のボタン。いつも同じ場所にあり、絞り込みの「クリア」が出ても動かない）＋ 画面の切り替え「**ボード｜読了一覧**」（`/` と `/read` へのリンク。今いる方を白文字で塗る：ボード＝読書中カラムと同じピンク `--col-reading-strong`、読了一覧＝読了カラムと同じ緑 `--col-read-strong`。S8）
  - 中：「**絞り込み：**」の見出しを先頭に 1 回だけ置き、「キーワード」（入力欄。タイトル・著者）・「ジャンル」・「タグ」・クリアを並べる（各欄の見出しは何で絞るか）。絞り込み中は、使っている欄の枠を濃紺グレー（`--slate` `#44546f`）で太くして地をうっすら色付きにし、「✕ クリア」を濃紺グレーの地に白文字で出す（どの条件が効いているかと解除の場所が一目で分かる）
  - 右：ログイン中のメールアドレス・「管理」（管理者のみ、S6）・「アカウント」（S7）・「ログアウト」
  - 部品：`BoardHeader.vue`（ヘッダ）・`BoardFilters.vue`（絞り込み）・`KanbanColumn.vue`（1 カラム分）。`KanbanBoard.vue` はデータの読み込み・ドラッグの結果の反映・モーダルの開閉を受け持つ
- **ヘッダの絞り込み**：キーワード検索（タイトルまたは著者名の部分一致。入力が 0.3 秒止まってから取り直す）／ジャンル選択／タグ選択（選択肢は自分の本に付いているタグ。絞り込みで減らないよう、絞り込み前の全件から集める）。3 つは併用でき、件数も連動する（[機能要件](functional-requirements.md) F11）。
- **読了カラムの並び替え**：読了カラム見出しに並び替え UI（読了日 / 評価 / 登録日 / 所要日数）＋昇順・降順トグル（▲＝昇順・▼＝降順）。既定は読了日・降順（F10）。同じ値の本はタイトル順。読了カラムはキーで並ぶため、カラム内のドラッグ並び替えはできない（他カラムからのドロップで状態変更のみ）。
- **操作**：「＋ 本を追加」ボタンで S3 を開く。カードをドラッグして別カラムへ移動（＝状態変更）。読みたい・読書中のカラム内ではドラッグで並び替え（順番を保存）。カードクリック（または Enter / Space）で S4 を開く。
- **空のカラム**：本が 1 冊も無いカラムには「まだありません」と出す。
- **読み込み・エラー**：取得中は「読み込み中…」、失敗時はメッセージと「再読み込み」ボタン。ドラッグでの移動・並び替えに失敗したときも同じ表示を出し、サーバーから取り直して元に戻す。操作中にログインが切れたらログイン画面へ戻る。
- **レスポンシブ**：PC は 3 カラム横並び。スマホは**縦積み**（1 カラムずつ縦に並べる）。

│  読みたい (3)      読書中 (2)      読了 (3) [読了日▼][▼]    │
│ ┌──────────┐   ┌──────────┐   ┌──────────┐          │

## 3. S2 書籍カード

- **表示項目**：
  - **書影（表紙）**：あればカードの左に幅 60px × 高さ 86px で出し、右に以下を並べる（無い本・画像が読み込めない本は今までどおりのカード）。1 画面の冊数がほぼ変わらず、表紙で見分けられる大きさとして、見本ページで 3 案（44px・60px・上に大きく）を比べて決めた
  - 主ジャンルのバッジ（色分け）、雑誌なら「雑誌」バッジ（白地に濃紺グレー `#44546f` の枠と文字。ジャンル・カラムの色と重ならない）
  - タイトル、著者、★評価（未評価なら非表示）
  - タグ（chip、複数）
  - 日付：現在のカラムに最初に入った日を「登録 / 開始 / 読了 + 日付」で 1 つ表示
  - 読了カードのみ「N日で読了」（所要日数。開始日と読了日が同じなら「当日に読了」。開始日が無いなど算出できなければ非表示）
- **バッジ配色**：ジャンルバッジは明るいパステル地＋同系の濃文字でトーンを統一（IT・技術 は黄 `#fff3c4` 地／`#7f5f01` 字）（プロトタイプ準拠。文字コントラストは WCAG AA 目安）。
- **操作**：クリック（または Enter / Space）で S4（編集）を開く。ドラッグで別カラムへ移動（＝状態変更、日付を記録）。

## 4. S3 追加フォーム

- **見出し**：「書籍を追加」。
- **ISBN / バーコードで登録**（フォーム先頭・追加時のみ）：ISBN/JAN 入力＋「検索」（入力欄で Enter でも検索）、カメラが使える環境（`BarcodeDetector` があり、HTTPS か localhost）では「📷 カメラ」でバーコード（EAN-13）を読取。読み取れたらカメラを止めてすぐ照会する。読取中は「停止」で止められ、カメラを起動できないときは「カメラを起動できませんでした。ISBN手入力をご利用ください。」を出す。取得成功でタイトル・著者を自動補完し、形態（書籍/雑誌）を自動セット。雑誌・該当なし・失敗時は手入力にフォールバック（[機能要件](functional-requirements.md) F6）。照会の結果は ISBN 欄の下に帯で出す：取得できた＝緑の帯「✓ 書誌情報を取得しました。」、該当なし＝黄色の帯「ℹ 該当が見つかりませんでした。…」（`role="status"` で読み上げにも伝える）。失敗はフォーム上部の赤いエラー。
- **表紙**：ISBN 照会で表紙（Google Books）が取れたら、ISBN 欄の下に「表紙」欄（60×86 の表紙＋「表紙を外す」）を出し、保存時に ISBN と表紙の URL も保存する。
- **入力項目**（上から）：タイトル（必須）、著者、**ジャンル｜ステータス**（横 2 列。ステータスの既定「読みたい」）、**形態｜★評価**（横 2 列。形態は書籍/雑誌、評価は「未評価」か ★1〜5）、**タグ**（入力して Enter またはカンマで chip として追加、× で削除。保存時に入力欄に残っている文字もタグとして確定する）、メモ（1 行の高さ。改行でき、右下のつまみで広げられる）。2 列の行は `.field-row`（CSS Grid で半分ずつの幅）。
- **タグ提案**：タグ欄の下に候補タグをクリック可能な chip で表示し、クリックで追加（F8）。並びは「タイトル・著者名に合う辞書の候補 → 自分が過去に付けたタグ（よく使う順）→ 定番タグ」。
  - **辞書**（`frontend/src/lib/tagSuggestions.ts` の `TAG_RULES`）：「この言葉がタイトル・著者名に含まれていたら、このタグを出す」の一覧。判定は部分一致なので、短い言葉は別の本にも当たる（例：「経」は「経済」、「神」は「神経」にも当たるため使わない）。内容は次のとおり。
    - 宗教・仏教・ブッダ・禅・神道・キリスト・聖書・イスラム・浄土・般若心経 → `宗教`
    - 論語・孔子 → `論語`／論語・孔子・老子・荘子・孟子 → `東洋思想` `古典`
    - 100分de名著・名著 → `名著解説` `シリーズ`／クライテリオン・表現者 → `評論`／文庫 → `文庫`／新書 → `新書`
    - 罪と罰・カラマーゾフ・戦争と平和 → `海外文学` `名著`／ドストエフスキー・トルストイ → `海外文学` `ロシア文学`
    - こころ・坊っちゃん・漱石・鴎外・太宰・芥川 → `日本文学` `名著`
    - 新渡戸・稲造 → `教養` `古典`／貝原・益軒 → `養生` `古典`
  - **定番タグ**（`GENERIC_TAGS`、どの本でも出す）：`名著` `再読したい` `積読` `宗教` `歴史`。
  - **表示**：最初は 8 件だけ表示し、残りがあれば「すべて表示（残り N 件）」で全部出す（「少なく表示」で戻す）。タグ欄に文字を打つと、その文字を含む候補（辞書の全タグも対象、前方一致を先）に絞り込み、候補を選ぶと入力中の文字は消える。入力済みのタグは出さない。各候補の「×」で**候補から隠せる**（本に付いているタグは消えない。辞書の候補も隠せる）。隠したタグは候補欄の下の「隠した候補（N）▼」を開くと一覧でき、「候補に戻す」で戻せる（設定はユーザーごとにサーバーへ保存）。
- **操作**：「追加」（登録して閉じる）／「キャンセル」（破棄して閉じる）。
- **エラー**：バックエンドの 422 のメッセージをフォーム上部に一覧表示。
- **表示形式**：モーダル。背景クリックかキャンセルで閉じる。入力中の内容を守るため、**Esc では閉じない**。
- **モーダルの外枠**：書籍フォーム・アカウント（S7）・管理（S6）は共通部品 `BaseModal.vue`（暗い背景・白い枠・見出し・背景クリックで閉じる・Esc で閉じる〔フォーカスの位置に関係なく画面全体で受ける。`closeOnEsc=false` で無効〕・開くとフォーカスを枠へ移し、閉じると開いたボタンへ戻す・画面より長い中身は枠内でスクロール）を使う。枠の幅は画面ごとに指定（書籍 440px・アカウント 400px・管理 460px）。
- **部品**：書籍フォーム（`BookFormModal.vue`）は、ISBN / バーコード欄を `IsbnLookup.vue`（照会・カメラ読取。結果だけを親へ渡す）、タグ欄を `TagInput.vue`（チップ入力・候補・隠す/戻す。`v-model` でタグ、`v-model:hidden-tags` で隠した候補）に分けている。入力欄の見た目（`.field` / `.field-label` / `.field input` など）は `src/style.css` に共通で置く。

## 5. S4 編集フォーム

- **見出し**：「書籍を編集」。
- **入力項目**：S3 と同じ（ISBN / バーコード欄は無い）。代わりに先頭に「**表紙**」欄：左に今の表紙（60×86、無ければ「表紙なし」）、右に ISBN 入力＋「表紙を取得」＋カメラ。**表紙と ISBN だけ**を更新し、タイトルなどは変えない（取れたら緑の帯「表紙を取得しました。」、無ければ黄色の帯で今の表紙のまま）。「表紙を外す」で消せる。
- **タグ提案**：S3 と同様。
- **操作**：「更新」／「削除」／「キャンセル」。削除は確認ダイアログ（`ConfirmDialog.vue`：「⚠ 本を削除しますか？」「『<タイトル>』を削除します。」「この操作は取り消せません。」＋「キャンセル」「削除」）で確かめてから実行する。開いた時点のフォーカスは「キャンセル」、Esc・背景クリックもキャンセル。
- **表示形式**：S3 と同じモーダル。

## 5.1 S5 ログイン / 新規登録 / パスワード再設定

- **ログイン**：メールアドレス・パスワード。下部の「招待コードをお持ちの方はこちら（新規登録）」で登録画面へ切り替え。「パスワードを忘れた場合は、管理者に再設定リンクを依頼してください」の案内を表示。
- **新規登録**：招待コード・メールアドレス・パスワード（8 文字以上）・確認。送信前に長さ・一致をヒント表示。成功するとログイン状態でボードを開く（本は空）。
- **招待リンク**：`/register?invite=<コード>` で開くと登録画面をコード入力済みで表示（以前の形式 `/?invite=<コード>` も転送される）。登録後はボード（`/`）へ移り、URL からコードが消える。
- エラー（招待コードが無効・メール登録済み・形式不正など）はフォーム上部に表示。
- **パスワード再設定**：管理者が発行した `/reset?token=<トークン>`（以前の形式 `/?reset=<トークン>` も転送される）で開くと、ログイン状態に関係なく再設定画面を表示。開いた時点でリンクを確認し、使えれば「<メール> の新しいパスワードを設定してください」とフォームを出す。無効・期限切れ・使用済みならフォームを出さずに、メッセージ・「必要なら、管理者に新しい再設定リンクを依頼してください。」・「ログイン画面へ」を表示。新しいパスワード（8 文字以上）・確認を入力し、成功するとそのユーザーでログインしてボードを開く（他の端末はログアウト）。URL からトークンを消す。無効・期限切れ・使用済みのリンクは「再設定リンクが無効か、期限切れです」。

## 5.2 S6 管理（管理者のみ）

- ヘッダーの「管理」ボタン（管理者だけに表示）からモーダルで開く。「招待」「ユーザー」のタブで切り替え。

**招待タブ**
- 「招待コードを発行」で新しいコードを一覧の先頭に追加。コードは 1 回限り・発行から 7 日で期限切れ。
- 一覧（新しい順）：コード・状態（未使用 / 使用済み / 期限切れ）。未使用・期限切れは期限、使用済みは「<登録したユーザーのメール> が登録」（そのユーザーが削除済みなら「削除済みのユーザー が登録」）。
- 未使用のコードは「リンクをコピー」（招待リンクをクリップボードへ）と「削除」ができる。

**ユーザータブ**

- ユーザー一覧（メール・管理者バッジ・登録日）。各ユーザーに「再設定リンクを発行」ボタン。
- 自分の行には「（自分）」を表示。自分宛ての発行はすぐには行わず、「あなた自身のパスワードを再設定するリンクです。今のパスワードが分かる場合は『アカウント』→『パスワード変更』を使ってください」と確認（「発行する」/「やめる」）を出す。禁止しないのは、ログインしたままパスワードを忘れた管理者の復旧手段として残すため。
- 発行したリンクはそのユーザーの下に表示し、「リンクをコピー」と期限（24 時間）を出す。リンクは保存されないため、モーダルを閉じると再表示できない（必要なら再発行）。

## 5.3 S7 アカウント

- ヘッダーの「アカウント」ボタンからモーダルで開く。「パスワード変更」「アカウント削除」のタブで切り替え。
- **パスワード変更**：現在のパスワード・新しいパスワード（8 文字以上）・確認。成功すると他の端末はログアウトされる。
- **アカウント削除**：現在のパスワード＋「すべてのデータが削除されることを理解しました」にチェックすると削除ボタンが押せる。削除後はログイン画面へ。最後の管理者は削除できない。

## 5.4 S8 読了一覧

- URL は `/read`（ログイン必須）。ヘッダの「読了一覧」で開き、「ボード」で S1 へ戻る。ヘッダ・絞り込み（キーワード・ジャンル・タグ）・並び替え・モーダルは S1 と共通で、切り替えても絞り込みの条件と読み込み済みの本は残る（同じ部品 `KanbanBoard.vue` が `view` で中身だけを切り替える）。
- **見出し**：「読了」＋件数（総件数）＋「**今年 N 冊・今月 N 冊**」（小さめの灰色の文字。読了日＝最初に読了になった日で数え、絞り込みには連動しない。開いたとき・保存/削除のあとに取り直す。取れなければ出さない）＋並び替え（読了日 / 評価 / 登録日 / 所要日数、▲▼。S1 の読了カラムと同じ設定を共有。部品は `ReadSortControl.vue`）。外枠は読了カラムと同じ灰色の地に緑の線。
- **並べ方**：読み込み済みの本を前半・後半に分け、前半を左の段、後半を右の段に並べる。各段の一番上に列の見出し「タイトル｜著者｜ジャンル｜（形態）｜評価｜読了日｜日数」を付け、行の各項目を見出しの下にそろえる（形態の列＝雑誌バッジの列は見出しの文字を出さない）。見出しと値のそろえ方は、タイトル・著者・ジャンル＝左、形態・評価・読了日＝列の中央、日数＝右（数字の桁をそろえる）。
- **1 行**：タイトル・著者・ジャンルのバッジ（長ければ … で省略。マウスを乗せると全体）・「雑誌」バッジ（形態が雑誌の本だけ。書籍は空欄）・★評価（未評価は薄い灰色の「—」）・読了日・所要日数（「N日」。開始日と読了日が同じなら「当日」、算出できなければ空欄）。タグは出さない（編集フォームで見る）。バッジの色は S2 と同じ（`src/style.css` の `.genre-*` / `.media-badge`）。
- **件数**：開いたときに 60 件まで読み込む。続きがあれば「もっと見る（残り N 件）」で 60 件ずつ追加。
- **操作**：行をクリック（または Enter / Space）で S4 を開く。ドラッグは無い。本が無ければ「まだありません」。
- **レスポンシブ**：幅 768px 以下では 1 段にし、列の見出しは出さず、1 冊を「タイトル」と「著者・ジャンル・雑誌・★・読了日・日数」の 2 行にする。
- 部品：`ReadList.vue`。
